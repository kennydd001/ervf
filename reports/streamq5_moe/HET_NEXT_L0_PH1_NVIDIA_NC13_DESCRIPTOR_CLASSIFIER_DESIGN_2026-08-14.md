# NC13 descriptor-driven classifier design

`reports/streamq5_moe/het_next_l0_ph1_nvidia_nc13_generic_topology_fixture_manifest.json` is normative. It contains six descriptors, five historical lock expectations, the exact current 80-path set and 198 generic cases.

`paths_for_revision` expands the seven fixed support templates for every token in `prefix`, flattens the twelve `phase_roots` arrays, validates paths and duplicates, and returns an ordinal set plus the exact in-progress patterns. `classify_topology` consumes only this return value, the descriptor caps and observed entry records; it contains no revision names or revision-specific branches.

Static preflight executes the production functions over every case. It must independently load each historical lock and prove exact set equality, then mutate each descriptor by dropped path, duplicate, wrong revision and wrong path. Current coverage mutates both file and directory observations at each generated path and every terminal/debris/composition state.
