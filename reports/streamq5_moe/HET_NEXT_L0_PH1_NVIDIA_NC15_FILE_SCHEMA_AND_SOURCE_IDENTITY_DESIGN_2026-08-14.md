# NC15 file-schema and source-identity design

`reports/streamq5_moe/het_next_l0_ph1_nvidia_nc15_semantic_identity_fixture_manifest.json` is normative. It extends every root with identity policy, binding key, stage policy and freeze-time expected identity fields; every observed entry contains parse state and root schema values.

The manifest freezes 118 current paths, all historical descriptors, 415 complete cases and a synthetic source-binding table with literal UTF-8 derivations, byte counts, Base64 and SHA-256. Static preflight must execute the production classifier over the full matrix and prove that design absence, implementation resolution and runtime validation are distinct states.
